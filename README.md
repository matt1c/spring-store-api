# Spring Store API

REST API для интернет-магазина, построенный на Spring Boot. Поддерживает аутентификацию через JWT, управление
пользователями с ролями, каталог товаров и систему заказов с резервированием остатков.

## Возможности

- **Аутентификация** - регистрация и вход через JWT-токены
- **Роли** - ROLE_USER, ROLE_ADMIN, ROLE_MANAGER с разграничением доступа
- **Товары** - CRUD-операции с пагинацией и сортировкой
- **Заказы** - создание заказов с автоматическим резервированием остатков на складе
- **Админ-панель** - управление пользователями (бан/разбан, назначение ролей)

## Система заказов

При создании заказа остаток товара **резервируется сразу** - количество списывается со склада в момент оформления. Это
гарантирует, что один и тот же товар не будет продан дважды.

- Если остатка не хватает — возвращается ошибка `400 Bad Request`
- При отмене заказа (`CANCELLED`) - зарезервированный остаток возвращается на склад
- При доставке (`DELIVERED`) - остаток уже списан, дополнительных действий не требуется

Каждая позиция в заказе хранит цену товара на момент оформления (`priceAtOrder`), поэтому изменение цены в каталоге не
влияет на уже созданные заказы.

## Обработка ошибок

Все ошибки API обрабатываются централизованно через `GlobalExceptionHandler` и возвращаются в едином формате
`ApiErrorResponse`:

```json
{
  "message": "Описание ошибки",
  "errorAt": "2026-09-05T04:45:00",
  "status": 400
}
```

Контракт ошибок API

## Контракт ошибок API

| Статус                    | Условие возникновения                                                                                                                                             | Пример тела ответа (`ApiErrorResponse`)                                                                                             |
|---------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------|
| 400 Bad Request           | Ошибки валидации DTO (`MethodArgumentNotValidException`), неверный тип аргументов, некорректное тело запроса                                                      | `{"message": "email - Некорректный формат email; price - Должно быть больше 0; ", "errorAt": "2026-09-05T12:00:00", "status": 400}` |
| 403 Forbidden             | Недостаточно прав доступа (`AccessDeniedException`, `AccessException`)                                                                                            | `{"message": "Access is denied", "errorAt": "2026-09-05T12:00:00", "status": 403}`                                                  |
| 404 Not Found             | Ресурс не найден (`UserNotFound`, `ProductNotFound`, `OrderNotFound`, `RoleNotFound`)                                                                             | `{"message": "User not found with id: 42", "errorAt": "2026-09-05T12:00:00", "status": 404}`                                        |
| 409 Conflict              | Конфликты бизнес-логики (`UserEmailAlreadyTaken`, `UserRoleAlreadyTaken`, `InsufficientStockException`, `UserPasswordIsAlreadyValid`, `UserAlreadyBanOrUnbanned`) | `{"message": "Недостаточно товара на складе", "errorAt": "2026-09-05T12:00:00", "status": 409}`                                     |
| 500 Internal Server Error | Системные и необработанные исключения (`SQLException`, `DataAccessException`, `NullPointerException` и др.)                                                       | `{"message": "Произошла непредвиденная ошибка: ...", "errorAt": "2026-09-05T12:00:00", "status": 500}`                              |

```bash
# Тесты
./mvnw test
```
